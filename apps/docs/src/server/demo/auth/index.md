title: Authentication
description: Try passkey registration, login, and logout.
---

Create an account with an email label and a passkey, then log out and sign in again. The dashboard shows the saved session and credentials.

Read the [Auth guide](/09-auth) to add this to your own application.

This demo runs only in development and saves test accounts in a local PGlite database. Setup instructions are in `apps/docs/README.md`.
