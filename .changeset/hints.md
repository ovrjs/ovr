- `Field.hint(text)` is what people read under a control in place of the field's description, for a description written to be complete for an agent. Agents still read the description, and an empty hint shows people nothing. A list's table lists each column's hint.
- A label in `options` given as a form renders may be an element, such as an image. An agent reading the page reads an image in a label by its `alt`.
