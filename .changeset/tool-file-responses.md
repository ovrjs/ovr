An MCP tool returns a file a route answers with: an image or audio as its own content, and any other type, such as a PDF, as an embedded resource. `resources/read` returns it as a `blob`. The call failed with an error before.

A date, time, month, week, or color field describes the format its picker sends, such as `YYYY-MM-DD`, in its JSON Schema, so an agent knows what to send.
